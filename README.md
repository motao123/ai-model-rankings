# AI 大模型第三方权威排行榜

> 在线地址：https://motao123.github.io/ai-model-rankings/

把散落在各家机构的 AI 大模型榜单聚到一屏的排行榜站点。同一模型在「真人偏好」与「客观基准」两类榜单上并列呈现，方便看谁全能、谁偏科。榜单数据原样搬运，只做聚合与可视化，不做二次加工。

## 收录榜单

| 榜单 | 类型 | 说明 |
|---|---|---|
| LMArena / Arena.ai 文本总榜 | 真人盲测（Bradley-Terry） | 用户盲测投票得出的偏好排名 |
| LMArena Code Arena / WebDev | 真人盲测 | 编程与网页开发方向的真人偏好 |
| LMArena Agent Arena | 真人盲测 | 智能体任务的真人偏好 |
| Artificial Analysis 智能指数 + 价格 | 客观基准（独立机构） | 综合能力指数，附 API 价格 |
| SuperCLUE 中文榜 | 客观基准（中文） | 面向中文能力的评测 |
| LiveCodeBench 编程榜 | 客观基准（防污染） | 随时间滚动出题，降低题目泄漏影响 |
| HF Open LLM Leaderboard v2 | 客观基准（开源 · 已退役归档） | 开源模型综合评测（归档快照） |

## 页面能做什么

- **多榜同屏**：真人偏好榜与客观基准榜并列，交叉对照；
- **变化追踪**：排名升降箭头、新上榜标记；
- **维度标签**：国产 / 厂商 / 开源等标签（厂商统一为标准名，识别不出就标「未标注」，不猜）；
- **档位归并**：同一模型的不同推理档位与期次（`-high` / `-max` / 思考模式 / 日期戳等）归并为一个模型，取其在该榜的最好名次，避免同一模型刷屏；
- **性价比象限图**：能力分 vs 价格，按性价比分区；
- **历史趋势**：单模型排名随时间变化的折线；
- **跨榜共识**：只列出现在两个以上榜单的模型，按上榜数与方法论覆盖度排序，并标注共识置信度；仅上榜一次的模型保留在分榜明细中；
- **数据新鲜度提示**：任一榜数据过期或降级时，页面顶部明确标注实际来源与滞后情况，不静默展示旧数据；
- **深浅双主题**：默认跟随系统，也可手动固定；图表配色随之切换。

## 数据与合规

- 所有分数与排名**原样搬运**，不修改、不加权、**不计算跨榜综合总分**；
- 每榜标注原始链接、更新时间与数据版权；页面显著位置有免责说明；
- 明确提示各榜口径不同、**不可直接横向比较**。

## 数据可靠性

单源抓取失败**不影响整体**——其余榜单照常更新，失败的那一榜会按可信度逐级回退，并在页面上标明该数据的**实际来源与滞后天数**（例如第三方镜像快照、上一批已校验数据、历史快照或人工兜底），绝不把降级数据当成实时数据展示。

无法判断数据是否可靠时宁可不展示；字段缺失一律显示「—」，不报错、不中断。持续降级会自动生成 Issue 提醒维护，恢复后自动关闭。

## 已知限制

- **SuperCLUE**：官方未提供 API，数据来自其公开的月度榜单文件；上游改版可能需要跟进适配，期间以最近一期数据兜底并在页面标注；
- **HF Open LLM Leaderboard** 已于 2025-03 退役，本站展示的是**归档数据集**，页面标注「已退役归档」；
- **Artificial Analysis** 无官方公开数据文件，依赖其页面公开信息，站点改版可能导致该榜短暂降级；
- **Internet Archive**（第三方镜像兜底）在部分网络环境不可达，属环境限制，不影响主链路。
